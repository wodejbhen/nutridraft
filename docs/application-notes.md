# 项目与后续申请说明

## 目前可以如实说明的事实

NutriDraft 是首次公开发布的离线营养标签科普工作台原型。项目使用 Python 3.10+ 标准库，从本地 JSON 读取数据，执行同一 g 或 ml 维度内的数值归一，并输出结构化报告、简报和模板化内容草稿。22 项本地自动测试已通过；GitHub CI 结果以仓库 Actions 页面为准。

GitHub 账号 `wodejbhen` 已由账号本人确认，项目公开仓库地址为 https://github.com/wodejbhen/nutridraft 。项目采用经用户确认的 MIT 许可证，版权署名为 `wodejbhen`。

工具不访问网络、不使用外部 API，也没有集成 Codex。模板输出不是 AI 推理，输入的 evidence 不经真实性核验。演示数据为合成数据，不含真实用户健康资料。工具不用于诊断、治疗或个体化医疗建议。

项目刚刚建立，没有可声明的长期维护、用户规模、下载量或生态影响证据。单次发布和测试不应描述成长期维护记录，也不能据此认定符合某项申请资格。
